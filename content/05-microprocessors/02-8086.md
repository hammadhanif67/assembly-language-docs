## Introduction to Intel 8086 Microprocessor

- The Intel 8086 is a 16-bit microprocessor developed by Intel in 1978. It is an early member of the x86 family of microprocessors.
- It is a 16-bit processor because its ALU and general-purpose registers primarily operate on 16-bit data.
- It has a 20-bit address bus, which allows it to address up to 1 MB of memory.
- It has a 16-bit data bus, which can transfer 16 bits of data in one bus operation.
- It supports pipelining through its Bus Interface Unit (BIU) and Execution Unit (EU).

## Two major functional units

### Bus Interface Unit (BIU)

- Fetches instructions from memory.
- Handles memory and I/O bus operations.
- Calculates physical addresses.
- Stores perfetched instruction bytes in a 6-byte queue.

### Execution Unit (EU)

- Decodes instructions.
- Executes instructions.
- Performs arithmetic and logical operations using the ALU.
- Uses registers and flags during execution.

## Bus Interface Unit (BIU)

The BIU manages communication between the processor and external memory or I/O devices.

Its major components include:

- **Segment Registers:** CS, DS, SS and ES.
- **Instruction Pointer (IP):** Holds the offset of the next instruction to be fetched.
- **Address Generation Circuitry:** Calculates the 20-bit physical address.
- **Instruction Queue:** Stores up to 6 bytes of prefetched instructions.
- **Bus Control Logic:** Controls transfers over the external bus.

## Execution Unit (EU)

The EU processes and executes the instructions supplied by the BIU.

Its major components include:

- **ALU (Arithmetic Logic Unit):** Performs arithmetic and logical operations.
- **General-Purpose Registers:** AX, BX, CX and DX.
- **Pointer and Index Registers:** SP, BP, SI and DI.
- **Flag Register:** Stores status and control flags.
- **Instruction Decoder and Control Circuitry:** Interprets instructions and coordinates execution.

## Registers of 8086

The 8086 provides 14 programmer-visible registers, each 16 bits wide.

| Register Category | Registers | Main Purpose |
|---|---|---|
| General-Purpose | AX, BX, CX, DX | Data and arithmetic operations |
| Pointer and Index | SP, BP, SI, DI | Stack, addressing and data movement |
| Segment | CS, DS, SS, ES | Identify memory segments |
| Instruction Pointer | IP | Offset of the next instruction to fetch |
| Flags | FLAGS | Status and control information |

The four general-purpose registers can also be accessed as separate 8-bit registers: AH/AL, BH/BL, CH/CL and DH/DL.

## Memory Segmentation

The 8086 uses a segmented memory architecture. A memory address is generated using a segment value and an offset.

The four main segments are:

- **Code Segment (CS):** Contains program instructions.
- **Data Segment (DS):** Usually contains program data.
- **Stack Segment (SS):** Used for stack operations.
- **Extra Segment (ES):** An additional data segment, often used in string operations.


## Pipelining in 8086

Pipelining is an important feature of the 8086. It allows instruction fetching and instruction execution to overlap.

:::diagram pipelining-8086
Figure: Pipelining in 8086 — Nonpipelined 8085 vs. Pipelined 8086
:::

- The BIU fetches instruction bytes from memory.
- The fetched bytes are placed in the instruction queue.
- The EU takes instructions from the queue and executes them.
- Meanwhile, the BIU can fetch subsequent instruction bytes.
- This overlapping of fetching and execution improves overall processing efficiency.

## Working of 8086

1. The BIU fetches instruction bytes from memory.
2. The bytes are stored in the instruction queue.
3. The EU takes the next instruction bytes from the queue.
4. The EU decodes and executes the instruction.
5. If memory access is required, the EU requests the BIU to perform the bus operation.
6. The BIU and EU continue their work with overlapping activity whenever possible.

The 8086 combines a 16-bit execution architecture, segmented memory addressing, a 20-bit address bus, and a 6-byte instruction queue to support efficient instruction processing.
