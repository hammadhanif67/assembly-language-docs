## Architecture of 8085 microprocessor

### Microprocessor

- A microprocessor is an electronic device fabricated on a single Integrated Circuit (IC) or chip.
- It performs the major functions of a Central Processing Unit (CPU).

### 8085 Microprocessor

- The 8085 is an 8-bit microprocessor developed by Intel in the mid-1970s.
- It is called an 8-bit microprocessor because it can process 8-bit data at a time.
- It was widely used in early microcomputer systems because of its simple architecture and ease of use.
- The 8085 provides the basic components required to fetch, decode, and execute instructions.
- The architecture of the 8085 microprocessor consists of several key components, including the accumulator, registers, program counter, stack pointer, instruction register, flags register, data bus, address bus, and control bus.

## Features of 8085 Microprocessor

- **General-Purpose Registers:** 8085 has six 8-bit registers — B, C, D, E, H, and L.
- **Program Counter (PC):** A 16-bit register that stores the address of the next instruction to be fetched from memory.
- **Stack Pointer (SP):** A 16-bit register that stores the address of the top of the stack and is used during stack operations.
- **Instruction Register:** An 8-bit register that temporarily holds the instruction fetched from memory for decoding and execution.
- **Flag Register:** An 8-bit status register containing five active flags: Sign (S), Zero (Z), Auxiliary Carry (AC), Parity (P), and Carry (CY).

## Arithmetic and Logic Unit (ALU)

ALU is the main processing unit of the 8085 that performs arithmetic and logical operations. It performs operations such as:

- **Arithmetic:** Addition, subtraction, increment, and decrement
- **Logical:** AND, OR, XOR, and comparison

The ALU operates primarily on 8-bit data.

The result of an ALU operation can affect the Flag Register.

## Flag Register

The Flag Register is an 8-bit status register in the 8085.It contains five active flags that indicate the status of the result produced by the ALU:

- Sign (S)
- Zero (Z)
- Auxiliary Carry (AC)
- Parity (P)
- Carry (CY)

The remaining three bits are unused/reserved.

## Accumulator (A)

- The Accumulator (A) is an 8-bit register directly connected to the ALU.
- It is used to hold data during arithmetic and logical operations.
- The result of many ALU operations is stored in the Accumulator.
- It also works with the internal data bus for data transfer within the processor.

## General-Purpose Registers

- The 8085 has six 8-bit general-purpose registers: B, C, D, E, H, and L.
- These registers can be paired to perform 16-bit operations:
  - BC pair
  - DE pair
  - HL pair
- W and Z are internal temporary registers used by the 8085 during certain internal operations.

## Program Counter (PC)

- The Program Counter (PC) is a 16-bit register in the 8085.
- It stores the memory address of the next instruction to be fetched and executed. After an instruction is fetched, the PC is updated to point to the next instruction.

> **For Example:** Suppose current value of Program Counter : [PC] = 4000H
>
> (It means that next executing instruction is at location 4000H.After fetching,program Counter(PC) always increments by +1 for fetching of next instruction.)

## Stack Pointer (SP)

- The Stack Pointer (SP) is a 16-bit special-purpose register in the 8085.
- It stores the memory address of the top of the stack.
- It is used during stack-related operations such as PUSH, POP, and CALL/RET instructions.
- The stack occupies a contiguous area of memory reserved for temporary data and return addresses.

### Temporary Registers (W and Z)

- W and Z are 8-bit internal temporary registers used by the 8085 for temporary storage during internal operations.
- They are not directly accessible to the programmer.

## Instruction Register and Decoder

- The Instruction Register (IR) is an 8-bit register that temporarily holds the instruction fetched from memory.
- The Instruction Decoder interprets the instruction and determines which operation the processor needs to perform.

## Timing and Control Unit

- The Timing and Control Unit coordinates and controls the execution of instructions in the 8085.
- It generates the required timing and control signals for communication with memory and I/O devices.
- Important signals include RD, WR, ALE, RESET, and status signals.
- It ensures that different operations of the processor occur in the correct sequence and timing.

## Interrupt Control

- An interrupt is a request that temporarily diverts the processor from its current program to handle an urgent event.
- After servicing the interrupt, the processor returns to the main program.
- The 8085 has five hardware interrupt inputs:
  - TRAP
  - RST 7.5
  - RST 6.5
  - RST 5.5
  - INTR
- Interrupt Priority: TRAP > RST 7.5 > RST 6.5 > RST 5.5 > INTR

## Address Bus and Data Bus

- **Address Bus:** The 8085 has a 16-bit unidirectional address bus used to specify the memory or I/O location that the processor wants to access. A 16-bit address bus can address 2¹⁶ = 65,536 locations (64 KB) of memory.
- **Data Bus:** The 8085 has an 8-bit bidirectional data bus used to transfer data and instructions between the processor, memory, and I/O devices. It can transfer 8 bits of data at a time.
- **Control Bus:** Consists of control signals that coordinate processor operations, such as Read (RD), Write (WR), and Address Latch Enable (ALE).
- **Multiplexing:** In the 8085, the lower-order address lines AD0–AD7 are multiplexed with the data bus. The ALE (Address Latch Enable) signal is used to separate the address and data during an operation.
